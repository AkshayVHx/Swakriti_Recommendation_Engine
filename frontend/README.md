# Swakriti Recommendation Engine

## Frontend Overview

This frontend provides the user-facing experience for the Swakriti recommendation engine. It guides users through a conversational intake flow, collects style preferences, and presents personalized results generated by the backend.

## Frontend Features

- Guided onboarding flow with a welcome screen and step-by-step question-based intake.
- Authentication experience for users to sign in and continue their recommendation journey.
- Voice intake support for capturing answers and interacting naturally.
- Dynamic question rendering based on the current recommendation state.
- Personalized result views that display recommended products with relevant details.
- Local storage support to preserve user progress and session data across refreshes.
- Clean component-based structure for questions, results, authentication, and voice interaction.

## Main User Flow

1. The user lands on the welcome screen and starts the recommendation flow.
2. The app asks a series of questions to understand preferences such as budget, style, occasion, and body type.
3. Voice input can be used to answer questions more naturally.
4. The collected state is sent to the backend for processing and recommendation generation.
5. The frontend displays the recommended products and relevant results to the user.

## Project Structure

- src/components: reusable UI components such as Welcome, Question, Results, VoiceIntake, and Auth.
- src/data: question definitions and intake content.
- src/utils: helper logic for storage and voice interactions.
- src/App.jsx: main application flow and state management.

## Setup

1. Navigate to the frontend folder.
2. Install dependencies with npm install.
3. Start the development server with npm run dev.
4. Open the local Vite URL in the browser to use the app.

## Tech Stack

- React
- Vite
- JavaScript / JSX
- CSS for styling
- Local storage for session persistence
